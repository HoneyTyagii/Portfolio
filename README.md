# 3D Portfolio Website

An immersive 3D portfolio built with React, Three.js, and GSAP featuring interactive 3D elements and smooth animations.

## Live Demo

[View Portfolio](https://honey-tyagii-portfolio.vercel.app/)

## Tech Stack 

- **Frontend**: React, TypeScript
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animations**: GSAP, Lenis
- **Styling**: CSS Modules

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- Interactive 3D scenes with custom lighting
- Smooth scroll animations
- Chess game integration
- Responsive design
